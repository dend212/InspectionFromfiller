### 2.2 Per-field source ranking and contradictions

`dedupeProposals` keeps one proposal per `kind:fieldPath` by `SOURCE_RANK = { permit: 3, assessor: 2, listing: 1, scan: 0 }` **before** docRank and confidence (`beats()`, `map-facts-to-fields.ts:308-321` wt). Right for system facts, wrong for property use: a permit describes the parcel when the system was built, the PUC is the current classification. **Rule — per-field override for exactly these two paths**, everything else unchanged:

```ts
const FIELD_SOURCE_RANK: Partial<Record<string, Record<PrefillSource, number>>> = {
  "facilityInfo.wastewaterSource": { assessor: 3, listing: 2, permit: 1, scan: 0 },
  "facilityInfo.facilityType":     { assessor: 3, listing: 2, permit: 1, scan: 0 },
};
const sourceRank = (p: ProposedField) => (FIELD_SOURCE_RANK[p.fieldPath] ?? SOURCE_RANK)[p.provenance.source];
```

Resolution: **assessor > listing > permit**; within permit, lower `authority.docRank` first (DA/ATC 0 < index 1 < NOT 2 — `permitDocRank` `:50-55`, `DOC_CLASS_RANK` `permits/doc-types.ts:21-28`), then strictly higher confidence. So DA typed 0.9 > DA bedroom inference 0.7 > NOT 0.85. Vacant/ag/blank PUC → listing wins → else best permit proposal (typed fills at 0.9, inference stays a 0.7 chip) → else blank.

Contradictions the inspector should still see: after the **final** dedupe, each dropped proposal for these two paths whose value differs from the winner and whose confidence ≥ 0.7 becomes a note on its own stage summary (`withNote`, `permits/index.ts:93-95`), e.g. "Permit OW-17-00474 lists 3 bedrooms (residential) — assessor codes the parcel commercial (PUC 1511); confirm". **Never emit a `warning` on a path that receives a `fill` in the same run** (one provenance slot per path — §5.1).

## 3. GP 4.02–4.23 checkboxes (`generalTreatment.systemTypes`) — final rule

Target: `string[]` over the 27 `GP402_SYSTEM_TYPES` tokens (`constants/inspection.ts:39-71`), one `FormFieldGroup` (one badge + one chip for the group, `step-general-treatment.tsx:92-103`), printed as set membership by `mapSystemTypeCheckboxes` (`field-mapping.ts:855-887`). Distinct from `facilityInfo.facilitySystemTypes` (Summary "Conventional / Alternative / Gray water", capped 0.7, `:231-240`).

```
tokens = ∅                                   (per extracted record, inside mapPermitFacts)
(a) gp402_conventional   if facts.systemType.value === "conventional"  OR (B1) generalPermitCodes ∋ "4.02"
(b) gp402_septic_tank    if any tanks[i] has capacityGal
                          AND tanks[i].model !~ /dosing|pump|lift|sump|aerobic|ATU|microfast|treatment/i
                          AND (once B1 lands) the tank is not the component under a 4.03–4.22 row
(c) DISPOSAL_TO_GP402[facts.disposal.type]: trench → gp402_disposal_trench · bed → gp402_disposal_bed ·
    chamber → gp402_chamber · seepage_pit → gp402_seepage_pit   ("other"/null → nothing)
(d) (B1) each code in generalPermitCodes matching /^4\.(0[3-9]|1\d|2[0-3])$/ → GP_CODE_TO_TOKEN
    4.03 composting · 4.04 pressure · 4.05 gravelless · 4.06 natural_evap · 4.07 lined_evap · 4.08 mound · 4.09 engineered_pad ·
    4.10 sand_filter · 4.11 peat_filter · 4.12 textile_filter · 4.13 denitrifying · 4.14 sewage_vault · 4.15 aerobic ·
    4.16 nitrate_filter · 4.17 cap · 4.18 wetland · 4.19 sand_lined · 4.20 disinfection · 4.21 surface · 4.22 drip · 4.23 large_flow
emit only if tokens ≠ ∅, ordered by index in GP402_SYSTEM_TYPES (valuesEqual is order-sensitive, merge.ts:50-56)
```

- **(b) is a fix**: `gp402Tokens` (`:63-77` wt) ticks `gp402_septic_tank` from *any* `capacityGal`. The prompt forces `model = "dosing tank"` only for dosing/pump tanks (`permit-extraction-prompt.ts:37`); an ATU is a separate 1500-gal row with free-text model ("BIOMICROBICS MICROFAST 0.9", as-built "Infiltrator IM1530", `epl_OW-24-00070-full.txt:43-47,75`) and today counts as a septic tank (numberOfTanks = 3, septic-tank box ticked from the 4.15 row). Same exclusion applies to `numberOfTanks` (A17).
- GP titles 4.02–4.23 **verified** against A.A.C. R18-9-E302–E323 (Supp. 25-2, `scratchpad/aac-18-09.txt:245-266`); 4.23 is "3000 to < 24,000 GPD" — `gp423_large_flow` is right, `sources.md` §3.2 C "Sequencing Batch Reactor" is wrong.
- Abandonment records emit nothing (prompt `:23`). `systemType === "alternative"` alone contributes **no** token (never guess a GP).
- **`generalTreatment.alternativeSystem` and `includeAlternativePages` — chips, cap 0.7** (`SYSTEM_TYPE_MAX_CONFIDENCE`): both change which report pages exist (`inspection-wizard.tsx:72`, `generate-report.ts:116-121`), the same reason `facilitySystemTypes` is capped. Today `:301` wt fills `alternativeSystem` at raw confidence and proposes nothing for `includeAlternativePages` → **fix** (decision 2). With B1, any 4.03–4.22 row drives both chips plus `facilitySystemTypes = ["conventional","alternative"]` when a 4.02 row is also present (form note: Section 5 combines with Section 4 when a septic tank is used). `generalTreatment.alternativeSystem` has no FormLabel → chip only, no badge (from code, not exercised — UNVERIFIED rendering).
- **Confidence** = min of contributing facts, no cap: a typed DA table (0.9/0.97/0.97 → 0.9) fills; a faint handwritten legacy ATC (0.7–0.85) fills or chips on its own merits. Stricter variant (cap 0.7 for `approval_to_construct` issued < 2001-01-01) is **not recommended** — the form still expects 4.02 for a tank-and-pit and the inspector would click the same answer every time (decision 4).
- **Caption**: `prov(primaryFact, { explanation })`, primary = disposal fact, else best tank, else systemType → "Permit OW-17-00474 · Discharge Authorization · GP 4.02 Conventional, Septic Tank, Disposal by Seepage Pit p.1"; with B1 "… · GP 4.02, 4.04, 4.15, 4.20, 4.22 p.1", evidence = the GENERAL PERMITS AUTHORIZED rows (`:470-483`). NOT keeps "(transfer record — secondary source)", docRank 2.
- **Dedupe**: one proposal per record; permit-class beats a NOT even when the NOT's array is longer (whole value, no union).
- **Recency tie-break — owner decision 1.** Two permit-class records (e.g. a 2000 ATC seepage pit and a 2024 Final DA drip system, both docRank 0) resolve on confidence alone (`beats()` `:315-321` wt) — a superseded system's cleaner scan can win `generalTreatment.systemTypes`, `numberOfTanks`, B1 codes. **Recommended default**: for system-describing paths (`generalTreatment.*`, `septicTank.*`, `disposalWorks.disposalType`, `designFlow.*`, `facilityInfo.facilitySystemTypes`) when source and docRank tie, prefer the record with the later `issueDate`/`finalDate` (carry a `recordDate` on `authority`), and suppress every record older than an abandonment on file (A13, R-15); confidence only after that. Alternative: keep confidence-only and rely on the inspector to pick the permit in the selection UI.
